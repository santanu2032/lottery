# CYS1 Subject Lottery 🎲

An interactive, physics-based spinning wheel application designed to fairly randomize and distribute academic subjects for the 12 groups of the CYS1 section. 

Built to ensure a transparent, visual, and conflict-free assignment process for class projects and presentations.

## 🚀 Live Demo
**[Play the CYS1 Lottery]([https://santanu2032.github.io/lottery/index.html])**

## ✨ Features
*   **Physics-Based Animation:** Smooth wheel rotation with randomized velocity and deceleration using HTML5 Canvas.
*   **Fair Distribution (No Replacement):** Once a subject ticket is won, it is removed from the active pool to guarantee exact distribution quotas.
*   **Real-Time Pool Tracking:** Visual dashboard displaying the remnant tickets available in the pool.
*   **Dark Mode UI:** Premium, high-contrast dark theme with vibrant neon wheel slices and ambient shadows.
*   **Custom Modal Reveals:** Dedicated pop-up announcements for each group (Groups A through L) with dynamic color-matching.
*   **Zero Dependencies:** 100% Vanilla JavaScript, HTML, and CSS. No frameworks required.

## 📚 Subject Distribution
The wheel is pre-configured to perfectly balance 5 subjects across 12 groups:
*   **Mathematics:** 3 Groups
*   **Physics:** 3 Groups
*   **Introduction to C:** 2 Groups
*   **Indian Knowledge System (IKS):** 2 Groups
*   **Environmental Science (EVS):** 2 Groups
